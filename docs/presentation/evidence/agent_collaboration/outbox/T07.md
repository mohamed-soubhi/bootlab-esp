## Deviations and doubts

1. **No pytest/ruff/mypy output to quote.** Docs-only, so the protocol's run commands do not apply; the checks above
   are what stands in for them. If the lead expects a markdown lint or a link check, say which and I will run it.
2. **Time budget wording (section 7).** Task says "BLE ~280 s/cycle at the drifted rate and WiFi ~32 s/cycle". Trap 24
   gives WiFi 29.7-32.9 s and BLE min 165.9 s / second-half median 280.5 s / worst 391.4 s. I wrote "WiFi cycles run
   ~32 s each, BLE cycles drift from ~170 s to ~280 s each over a long run" and, per the task, computed no total.
   The ~170 s lower bound is my rounding of Trap 24's 165.9 s minimum, not a figure from the task text — change it if
   you want only the medians.
3. **`manifest` claim kept minimal.** `soak_random.main` calls `poolmanifest.load_manifest`; the doc says the manifest
   "is loaded from it". `docs/BL069_IMAGE_POOL.md` also describes `validate_manifest` re-checking the contract, but
   `soak_random.py` does not call it, so I did not claim validation happens. Tell me if the runbook should state the
   stronger promise anyway.
4. **`stopped_early` has no CLI flag.** `_report` sets it from `stopped`, which only `run_soak(stop_after=...)` can
   raise — `main()` never passes it, so no CLI option exposes it. Documented as "a `stop_after` limit" rather than as
   a flag; say so if you would rather it be dropped from the table.
5. **`--pool` help text vs. reality.** The flag help says "directory with the BL-069 pool (manifest.json + .bin
   files)", which is what the doc repeats. The `.bin` files are only read for `generated` picks
   (`_image_path`); fixed and failure images resolve through `backend.image_for`. I did not spell that split out.
6. **Warm-up failure path.** A failed warm-up raises `SoakError` out of `run_soak`, which `main` turns into an
   `ERROR:` line and exit 2 — so the doc files it under "configuration and precondition problems exit 2" rather than
   under the exit-1 pass criteria. Flagging in case you consider a warm-up failure a test failure instead.

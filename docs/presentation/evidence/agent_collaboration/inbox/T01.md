# T01 — `host/labflash/imagegen.py`
Make `host/tests/test_imagegen.py` pass. Read that file first; it is the spec. Do not edit it.

Imports you may use: `hashlib`, `dataclasses`, `labflash.imagefmt` (SLOT_SIZE, SECTOR), `labflash.pinpolicy` (SAFE_OUTPUT_PINS). Both exist.

## Public API
    MAX_VALID_PAD = 2_500_000
    ROLES = ("valid", "unaligned_trailer", "near_limit", "too_big")

    @dataclass(frozen=True)
    class Variant:
        seed: int; role: str; version: str; pad_bytes: int; blink_ms: int
        led_rgb: tuple[int, int, int]; pins: tuple[int, int]
        trailer_len: int; target_len: int | None

    def pad_blob(seed: int, n: int) -> bytes        # hashlib.shake_256(f"pad:{seed}".encode()).digest(n)
    def seed_for(seed_base: str, index: int) -> int # int.from_bytes(sha256(f"{seed_base}:{index}".encode()).digest()[:8], "big")
    def gen_variant(seed: int, role: str = "valid") -> Variant
    def defaults_text(v: Variant) -> str
    def gen_pool(seed_base: str, n: int = 13) -> list[Variant]

## Rules for gen_variant
- Deterministic: derive every parameter from `hashlib.shake_256(f"variant:{seed}".encode())` bytes, NEVER `random`.
  Use distinct byte slices per field so fields are independent.
- `version = "gen-" + hashlib.sha256(str(seed).encode()).hexdigest()[:8]`.
- `pad_bytes`: role "valid" and "unaligned_trailer" -> uniform-ish in [0, MAX_VALID_PAD]; "near_limit"/"too_big" -> 0.
- `blink_ms` in [100, 1000]. `led_rgb`: each 0..255, never (0,0,0). `pins`: two DISTINCT members of SAFE_OUTPUT_PINS
  (pick from `sorted(SAFE_OUTPUT_PINS)`), returned in that pick order.
- `trailer_len`: "unaligned_trailer" -> 1..4095; every other role 0. `target_len`: "near_limit" -> SLOT_SIZE,
  "too_big" -> SLOT_SIZE + SECTOR, every other role None.
- Unknown role -> `ValueError`.

## defaults_text(v)
Exactly these lines, in this order, each ending `\n`, no comments, no blank lines:
    CONFIG_APP_GEN_POOL=y
    CONFIG_APP_REPRODUCIBLE_BUILD=y
    CONFIG_APP_GEN_PAD_BYTES=<pad_bytes>
    CONFIG_APP_GEN_BLINK_MS=<blink_ms>
    CONFIG_APP_GEN_LED_R=<r>
    CONFIG_APP_GEN_LED_G=<g>
    CONFIG_APP_GEN_LED_B=<b>
    CONFIG_APP_GEN_PIN_A=<pins[0]>
    CONFIG_APP_GEN_PIN_B=<pins[1]>

## gen_pool(seed_base, n=13)
- `n < 13` -> `ValueError`. Roles by index for n == 13:
  `("valid","valid","valid","unaligned_trailer","valid","valid","near_limit","valid","valid","unaligned_trailer","valid","valid","too_big")`.
  For n > 13, insert `n-13` extra "valid" roles just before the final "too_big".
- Item i is `gen_variant(seed_for(seed_base, i), roles[i])`.
- All 9+ valid pads must be distinct and span >= 1_000_000 bytes for the test seed bases; if random draws collide or
  cluster, that is a real defect: fix by drawing better, not by editing tests.

## Public API
    SCHEMA = 1

## expected_outcomes -> {"wifi": {"accept": bool, "reason": str}, "ble": {...}}
- valid: both accept. near_limit: both accept (image fills the 4 MB slot exactly).
- unaligned_trailer: wifi accepts (bootloader ignores bytes after the signature sector), ble REJECTS with a reason
  containing "4096" (host refuses images that are not 4096-aligned).
- too_big: both reject (exceeds the slot). Unknown role -> ManifestError. Every reason is a non-empty string.

## make_entry
Keys exactly: index, seed, role, version, file, size (=len(data)), signed_len, trailer_len (=size-signed_len),
sha256 (hexdigest of data), params {pad_bytes, blink_ms, led_rgb (list), pins (list)}, expected (expected_outcomes).
Raise ManifestError if computed trailer_len != variant.trailer_len.

## make_manifest -> {"schema": 1, "seed_base": seed_base, "slot_size": SLOT_SIZE, "images": entries}

## validate_manifest raises ManifestError (message must contain the quoted word) when:
"schema" != 1 · duplicate "version" · duplicate "file" · sha256 not 64 lowercase hex · "size" not an int ·
"index" values not exactly 0..n-1 in order · role in (valid, near_limit) and size % 4096 != 0 → "aligned" ·
"too_big" entry claims accept=True on either transport → "too_big" · unaligned_trailer entry claims ble accept=True →
"ble" · a non-too_big entry with size > slot_size → "slot" · fewer than min_valid non-too_big entries → "12" ·
fewer than 8 distinct sizes among non-too_big entries → "spread". Check in whatever order makes each test's message appear.

## write/load
`write_manifest`: validate first (invalid -> raise BEFORE creating any file), then
`json.dumps(m, indent=2, sort_keys=True) + "\n"`, no timestamps anywhere. `load_manifest`: read, validate, return dict.
